# 録画用HDDへの保存とRAM実行

本体の内部フラッシュを書き換える代わりに、ソース・ビルド済み実行ファイル・局設定を外部サーバまたは自分のHDDへ保存し、起動時に`/tmp/mt/`へ投入する構成とした。実行場所はRAMのままなので電源断で消える。

開発では録画用USB HDDへ成果物を保持し、電源リセット後に戻せることを確認した。公開版はHDDの識別・初期化・mount・復旧操作を自動化する実験スクリプトを同梱しない。誤ったデバイスの初期化や個別環境依存の操作を避けるためであり、通常の外部保存まで禁止するものではない。

本体のRAMは限られる。過去に大きな証跡archiveをtmpfsへ一旦生成してメモリ不足・UI異常を起こした。大きな保存物はホスト側で作り、必要なファイルだけをRAMへ転送する。放送TSや調査dumpは公開リポジトリへ入れない。

ソースから作ったバイナリと公開局表だけをまとめるには`tools/mkra-watch/make_bundle.py`を使う。[再投入手順](MKRA-AUTO-RESTORE.ja.md)を参照。
