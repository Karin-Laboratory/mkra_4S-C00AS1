## 判定基準

HTTP200、復調lock、codec認識、CAS transport成功だけではAV成功ではない。同期/TEI/CC/CRC、PATの要求TSID、主AVの実decode、終了・所有graphの解放を別々に確認する。`cleanup_ok=true`やsubscriber drop0を全標本の全frame完全性の証拠にしない。境界PES・DTS・AAC警告と未測定項目を記録し続ける。
